# digital-privacy-website

## Overview 
This is a multi-page website focused on digital privacy, user rights, cybersecurity concepts, and major privacy laws.
This project was created for a web development course and demonstrates basic front-end development skills using HTML and CSS

## Features
- Multi-page website structure
- Navigation menu across pages
- Informational content about digital privacy and user rights
- Contact or quiz form elements
- Consistent styling with CSS
- Sitemap and project documentation

## Technologies used
- HTML
- CSS
- GitHub

# What I learned
Through this project, I practiced building and organizing a complete website, creating navigation, styling content, and writing clear content for users. I also learned about privacy online and how it may connect to business and technology.
